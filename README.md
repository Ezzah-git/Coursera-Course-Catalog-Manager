# Coursera Catalog Management System

A Java-based Course Catalog Management System developed using Object-Oriented Programming (OOP), Java Collections, and File Handling concepts. The system fetches course data from a CSV file and provides functionalities to manage, search, and analyze courses efficiently.

---

## Features

- Load course data from a CSV file
- Add and manage courses dynamically
- Search courses by title
- Filter courses by difficulty level
- Count courses organization-wise
- Efficient data storage using `HashMap`

---

## Technologies Used

- Java
- OOP Concepts
- Java Collections (`HashMap`)
- File Handling
- CSV Data Processing

---

## Concepts Implemented

- Classes & Objects
